# World Happiness Report Dashboard

An interactive Power BI dashboard exploring what actually separates the happiest nations from the least happy — with a dynamic "explore any country" feature covering all 168 countries in the dataset.

## What it does
- Global snapshot of happiness scores by region
- Explores what factors actually drive happiness (GDP, social support, freedom, and more)
- Side-by-side comparison of any two countries
- Deep-dive into any single country's 15-year trend, compared to its region and the world

## Data source
World Happiness Report 2026, official data (2011–2025)

## Tools used
Power BI Desktop, DAX, Power Query
